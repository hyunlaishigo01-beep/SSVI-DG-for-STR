# SSVI-DG-for-STR
## SSVI-DG for Support Tensor Regression

This repository provides the MATLAB implementation of the proposed safe 
screening framework (SSVI-DG) for support tensor regression (STR).

The implementation includes:

- Rank-1 Support Tensor Regression with SSVI-DG
- Higher-Rank Support Tensor Regression (HR-STR) with SSVI-DG


## Requirements
This code requires the Tensorlab toolbox for tensor-related operations. 
The required toolbox is included in the SURF repository:

https://github.com/LifangHe/SURF.

## Note

The current version provides the main implementation of the proposed framework.
